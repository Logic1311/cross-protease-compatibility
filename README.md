The main result is a deterministic, model-conditional diagnostic for recorded paired assay intervals. The paired budget follows from an interval-intersection reduction; the graph algorithm and the prior detection of thermodynamic coupling on the measured panels are not new. The contribution is this paired diagnostic and its fixed-witness application, not an independent wet-lab validation or a new molecular mechanism.

For reproduction, extract the current archive and read its README. It pins the processed input from [Tsuboyama et al. on Zenodo](https://zenodo.org/records/7992926). The public integer Lean statements do not formalize the real-valued graph theorem or validate empirical inferences.
